# HAR Skills Documentation Site

This directory contains the source for the HAR Skills VitePress documentation site.

## Local Development

Prerequisites:

- Node.js 22+ (recommended)
- npm 10+

```bash
# 1. Install dependencies
cd website
npm install

# 2. Start the development server with HMR
npm run docs:dev
# Open http://localhost:5173

# 3. Build for production
npm run docs:build
# Build output is written to website/.vitepress/dist

# 4. Preview the production build locally
npm run docs:preview
# Open http://localhost:4173
```

## Directory Structure

```
website/
├── package.json              # Dependencies and scripts
├── .vitepress/
│   ├── config.ts             # VitePress site configuration
│   ├── theme/                # Custom theme
│   └── dist/                 # Build output (gitignored)
├── public/                   # Static assets copied as-is
│   └── assets/
│       └── har-skills-feature-tree.svg   # Capability tree SVG (generated by CI)
├── en/                       # English documentation
└── zh/                       # Documentation pages
```

## Capability Tree SVG

The capability tree SVG is regenerated automatically during CI by `scripts/render_feature_tree.py` at the repository root — no manual maintenance needed.

To regenerate locally:

```bash
# Run from the repository root
python scripts/render_feature_tree.py
cp docs/assets/har-skills-feature-tree.svg website/public/assets/har-skills-feature-tree.svg
```

## Adding New Pages

1. Create a new `.md` file under `website/en/` or `website/zh/`.
2. Use YAML frontmatter at the top for metadata:

   ```markdown
   ---
   title: Page Title
   ---
   ```

3. Reference the new page in the corresponding `index.md` or sidebar configuration so it appears in navigation.
4. Keep localized page content in sync.

## Deployment

Pushing to `main` with changes under `website/**` triggers the `.github/workflows/docs.yml` GitHub Actions workflow, which builds and deploys to GitHub Pages automatically.
